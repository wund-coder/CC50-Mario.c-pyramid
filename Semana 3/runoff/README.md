# Runoff - CC50

Programado em C.
O código inteiro não foi escrito por mim e sim fornecido pelo próprio CS50, minha função no código foi implementar e completar "Votes, Tabulete, Print_Winner, find_min, is_tie, eliminate".
O intuito do código é funcionar igual o anterior "plurality", o qual funcionava em um sistema de eleição, aonde o usuário poderia votar em um candidato.
O diferencial do Runoff é que ele é mais complexo, funcionando como diversas rodadas de votos, conseguindo escolher um candidato de primeira preferência, outro de segundo e outro de terceira.
O usuário poderá escolher quantas rodadas ele deseja que sejam realizadas no total de 100 e com no máximo 9 candidatos.
No final do programa, ele exibirá o nome do candidato vencedor, caso ocorra algum empate, ele exibirá o nomes dos empatados.
NOTA:O programa solicita que o nome do Candidato seja o mesmo na hora dos votos, letras maiúsculas, minúsculas, etc... Caso o contrário o programa se encerrará.
